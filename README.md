# JEE Formula Hub

Futuristic dark study UI based on the supplied dashboard reference.

### Important accuracy note
The official JEE Main 2026 syllabus is published by NTA and the JEE Advanced 2026 syllabus is published in the official brochure. The website's chapter map is based on those syllabus structures, and the bundled formula JSON is a **core formula bank**, not a mathematically certified list of every possible identity/derived relation. I am not going to falsely label a finite generated file as “literally every formula” without a chapter-by-chapter audit.

Official sources:
- JEE Main 2026 syllabus: https://jeemain.nta.nic.in/document/syllabus-2026/
- JEE Advanced 2026 information brochure/syllabus: https://jeeadv.ac.in/documents/IBEnglish_2026.pdf

### Run
Serve this folder with a local HTTP server, for example:
`python -m http.server 8000`
Then open `http://localhost:8000`.
